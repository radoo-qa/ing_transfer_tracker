# ING Transfer Racker

A personal, non-commercial Node.js application for local financial data management using Enable Banking API.

## Purpose

The project is intended for personal use with bank accounts owned by the application operator.

## Environment

- Node.js
- Local HTTPS
- Enable Banking API
- Production restricted mode

## Documentation

- [Privacy Policy](PRIVACY.md)
- [Terms of Service](TERMS.md)

## Security

Private keys, API credentials, access tokens, bank data and local TLS certificates must never be committed to this repository.
